Section 2 — Technical SEO Audit

🔴
Page Speed & Core Web Vitals — CRITICAL
Elementor-based sites are typically slow due to large CSS/JS bundles, render-blocking resources, and unoptimized image loading. Medical sites require LCP under 2.5s. Heavy slider on homepage and multiple images without lazy loading are likely causing poor CWV scores.
Fix: Use WP Rocket or LiteSpeed Cache. Convert all images to WebP. Enable lazy loading. Defer non-critical JS. Remove unused Elementor widgets/CSS. Target LCP <2.5s, TBT <200ms, CLS <0.1.
Critical
🔴
Missing Structured Data / Schema Markup — CRITICAL
No LocalBusiness, MedicalBusiness, Physician, or FAQPage schema detected. Google uses schema to power rich results, knowledge panels, and local pack listings. Competitors with schema will consistently outrank this site.
Fix: Add LocalBusiness + MedicalBusiness schema on homepage. Add Physician schema on Meet The Doctor page. Add FAQPage schema on all service pages. Add AggregateRating schema to embed review data.
Critical
🔴
Title Tag Inconsistency — Neurologist vs Neurosurgeon
Browser tab says "Best Neurologist In Gurgaon" while OG title says "Neurosurgeon in Gurgaon." Neurologist and Neurosurgeon are completely different specialties. This confuses Google and patients, and dilutes keyword targeting. This is a YMYL (Your Money Your Life) domain — accuracy is critical for E-E-A-T.
Fix: Standardize all title tags to "Best Neurosurgeon in Gurgaon | Dr. Vikas Kathuria | Brain & Spine Clinic." Remove all "Neurologist" references if doctor is not a neurologist.
Critical
🔴
NAP Inconsistency (Name, Address, Phone)
Three different phone numbers found: 9267939247 (header click-to-call), +91-8377080260 (logo area), 9215151260 (WhatsApp). Google cross-references NAP across your website, GMB, Practo, Justdial, and other directories. Inconsistencies hurt local SEO significantly.
Fix: Choose ONE canonical phone number. Update it consistently across the website, Google Business Profile, Practo, Justdial, Sulekha, IndiaMART, and all other listings.
Critical
🔴
Google Business Profile Not Fully Optimized
The website links to GBP but the profile likely lacks full optimization — no services listed with descriptions, no posts, no Q&A section populated, no attributes set (e.g., "Specializes in Brain Tumor Surgery"). GBP is the #1 factor for local map pack ranking.
Fix: Add all 20+ services to GBP with keyword-rich descriptions. Post weekly updates. Answer all Q&A. Add all attributes. Upload 50+ real photos. Get more Google reviews (currently on Practo — need Google reviews too).
Critical
🟡
XML Sitemap & Robots.txt — Unverified
Cannot confirm if sitemap.xml is submitted to Google Search Console or if robots.txt is properly configured. Elementor sites sometimes block CSS/JS files in robots.txt which hinders Googlebot rendering.
Fix: Submit sitemap to GSC. Check robots.txt allows Googlebot access to all CSS and JS. Verify all important pages are indexed via GSC.
Warning
🟡
Mobile Usability — Elementor Breakpoints
Elementor sites frequently have mobile rendering issues — overlapping elements, large tap targets, text too small. With 65%+ of medical searches on mobile in India, any mobile UX issue directly kills conversions and rankings.
Fix: Audit all pages on mobile (iPhone 12 + Android). Check tap targets ≥48px. Ensure no horizontal scroll. Use Elementor's responsive mode to fix breakpoint issues.
Warning
🟡
Image Optimization — Missing ALT Tags & File Names
Multiple images have generic names (1.jpg, 2.jpg, about.jpg) and ALT text shows only "Best Neurosurgeon in Gurgaon" repeated. This is a missed keyword opportunity and accessibility violation.
Fix: Rename all images descriptively (e.g., dr-vikas-kathuria-brain-tumor-surgery-gurgaon.webp). Write unique, descriptive ALT text for every image. Convert to WebP. Compress all images below 100KB.
Warning
🔵
Elementor 3.34.2 — Keep Updated
Running on Elementor 3.34.2. Outdated plugins are a security risk and can cause compatibility issues with newer WordPress versions.
Fix: Keep Elementor, WordPress core, and all plugins updated. Use a staging environment before major updates.

Section 3 — On-Page SEO Audit

🔴
Thin Content on Service Pages
Service pages like Brain Tumor, Cervical Spine Surgery, etc. likely have under 500 words of actual content. Google's Helpful Content Update penalizes thin medical content. Competitors have 1500–3000 word in-depth pages for the same procedures.
Fix: Expand every service page to minimum 1200–2000 words. Include: What is the condition, Symptoms, Causes, Diagnosis, Treatment options, Why choose Dr. Kathuria, Recovery, FAQs. Add schema.
Critical
🔴
Weak Meta Descriptions (Same text reused)
The same meta description "Brain & Spine Neuro Center offers consultation and care for brain and spine conditions..." appears to be used for all pages. Each page needs a unique, compelling meta description with the target keyword and a call-to-action. Click-through rate (CTR) from search depends on this.
Fix: Write unique 150–160 character meta descriptions for every page. Include primary keyword, doctor name or specialty, and action phrase like "Book Consultation Today."
Critical
🟡
H1 Tag Issues
Homepage H1 appears to be "About Brain & Spine Neuro Center" rather than the primary keyword. The H1 should contain the most important target keyword.
Fix: Change homepage H1 to "Best Neurosurgeon in Gurgaon – Dr. Vikas Kathuria" or similar. Each page should have exactly one H1 containing the page's primary keyword.
Warning
🟡
Internal Linking — Not Strategic
Internal links exist via the menu, but service pages don't cross-link to related pages, blog posts don't link to service pages, and there's no clear "hub and spoke" linking architecture to pass authority efficiently.
Fix: Build a linking matrix. Each blog post links to 2–3 relevant service pages. Each service page links to related services. Add "You May Also Be Interested In" sections. Link doctor page from all service pages.
Warning
🟡
Blog Content — Low Volume & Frequency
Only 3 recent blog posts found. Blog was last updated March 2026. To compete for informational keywords and build topical authority, a neurosurgery website needs 4–8 high-quality posts per month.
Fix: Create a content calendar. Publish at minimum 2 posts/week covering: symptoms, conditions, treatment comparisons, patient education, "best doctor for X in Gurgaon" type posts. Target long-tail keywords with low competition.
Warning
🟡
No E-E-A-T Signals on Key Pages
YMYL (health) pages require high E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness). The doctor's credentials page exists but qualifications, publications, hospital affiliations, media mentions, and awards are not prominently featured on service pages.
Fix: Add "Medically reviewed by Dr. Vikas Kathuria, M.Ch (Neurosurgery)" to every article. Display credentials on all service pages. Link to PubMed/research if available. List all hospital affiliations prominently.
Warning
